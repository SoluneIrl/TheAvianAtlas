# 🕊️ The Avian Atlas

**My Digital Bird Watching Journey** — Vol. I

I hope this little project of mine reflects both my love for birds and gaming. I don’t see myself stopping anytime soon, and I can’t wait to keep adding to it and watching this collection grow! 

People who helped me in finding birbs are credited below the respective cards.

---

## ✨ Features

- **Browse by game**
- **Lightbox Viewer**
- **Sorting**
- **Field Tally**
- **Ambient Music Toggle**
- **Reduced-motion Friendly**
- **Responsive Layout for All Devices**
- **Fun Rave Mode**
- **Easter Eggs**

## 🛠️ Core Tools Used

- **HTML for layout**
- **CSS for styling**
- **JS for adding functionality**
- **CSVs as my database**
- **Python for automatically filling up the CSVs**

## 🛠️ External Tools Used
- **Youtube for further research**
- **Games and their official and fandom Wikis for more information**
- **Reddit and Steam for Collaboration with other people**
- **Upscaly to increase image resolution**
- **GIMP for editing Webp format images**
- **Remove.bg and Apple's Clean Up Tool for clearing images**
- **Canva for making the photo collage**
- **ChatGPT for generating the Website's Logo and a stylised artwork of me**
- **Claude for helping me with bug fixes**
- **Song used in the website is from Aniimo called Under Neon Lights**
- **Github for hosting the website**
- **Jetbrain's Webstorm as the IDE**
- **LocalSend for sending images between devices**
- **ShareX and Steam's Screenshot and Recording Tool**
- **Svgrepo.com for SVGs as some of the Website's Assets**
